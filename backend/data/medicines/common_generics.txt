# entries.

# What this list is NOT

# It is not complete, and it is not authoritative. A name that does not appear
# here means only "not in this list" -- never "not a real medicine". Nothing
# in the app may treat absence from this file as evidence of anything, and no
# name is ever rewritten automatically on the strength of a match. The list
# exists to offer the reader a possible correction to confirm or reject.
#
# Maintaining it: one lowercase generic name per line, blank lines and lines
# starting with '#' ignored. Do not add brand names -- a brand match would
# suggest replacing what the doctor actually wrote.
