# Antigravity Flutter Engineering Skill Pack

Copy the `.agents` folder into the root of your Flutter project.

Included skills:
1. product-manager
2. ui-ux-expert
3. flutter-expert
4. software-architect
5. security-engineer
6. qa-engineer
7. production-release-manager
8. marketing-growth
9. ai-llm-engineer
10. backend-database-engineer

After copying, start a new Antigravity conversation. Antigravity can activate relevant skills automatically from their descriptions. You can also manually invoke a skill with `/<skill-name>`.

Recommended flow:
Requirement → Product → UX → Architecture → Security → Flutter → Backend if needed → QA → Release → Marketing/Analytics
